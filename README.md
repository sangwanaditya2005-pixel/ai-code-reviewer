
# AI Code Reviewer & Explainer

An AI-powered application that helps developers review their code, understand functions, and generate unit tests.

## Tech Stack

- Frontend: React + Vite
- Backend: Node.js + Express
- Database: MongoDB
- AI: Google Gemini API
- Authentication: JWT
- Integration: GitHub API

## Core Features

- AI-powered code reviews
- Function explanations
- Unit test generation
- GitHub repository integration
- User authentication

## Project Status

Currently in development.
